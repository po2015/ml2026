一家出口商的新网站上线了。在办公室里，快得飞起；建站公司的演示也完美无缺。六个月后，来自东南亚和非洲的自然流量只有预期的三分之一，移动端跳出率高达 70%。终于有人做了诊断：在雅加达或内罗毕，一部中端手机走 4G 网络，网站要 8–11 秒才能正常使用——而这恰恰是这个网站的目标市场。Google 比销售团队更早发现了这一点。Core Web Vitals 是 Google 衡量你的*买家*实际体验的方式，而对出口商来说，「总部很快」和「目标市场很快」之间的落差，正是排名和询盘流失的地方。

## 三个指标，用大白话讲

Core Web Vitals 是 Google 从真实用户的浏览器（访问你网站的 Chrome 用户）实测的三个数字，而不是实验室测试：

| 指标 | 衡量什么 | 商业翻译 | 「良好」阈值 |
|---|---|---|---|
| **LCP**（Largest Contentful Paint，最大内容绘制） | 主要内容何时出现 | 买家要盯着空白或残缺页面看多久 | ≤ 2.5 s |
| **INP**（Interaction to Next Paint，交互到下次绘制） | 页面响应点击/点按的速度 | 点下去时网站感觉是流畅还是卡死 | ≤ 200 ms |
| **CLS**（Cumulative Layout Shift，累计布局偏移） | 加载过程中布局跳动的幅度 | 买家正要点的按钮会不会突然跑掉 | ≤ 0.1 |

三项全部达标的页面会获得（小幅的）排名优势，更重要的是，它们*给人的感觉*专业。不达标的页面则双重受损：排名上吃点小亏，间接损失却很大——在页面加载完之前就离开的买家不可能转化，而他们的跳出又告诉 Google 这个页面没有满足需求。

## 为什么出口商默认就不达标

三个结构性原因，都可以修复：

**1. 距离。** 你的服务器在中国（或托管在国内），你的买家在圣保罗、利雅得、拉各斯、华沙。每个请求都要跨越大洋——单次往返就有 200–400 ms 延迟，而一个页面需要几十次往返。解法是 [CDN 与边缘缓存这套基本功](/zh/news/export-website-speed-cdn-performance/)：从物理上靠近买家的节点分发网站。仅这一项通常就能让远端市场的 LCP 减半。

**2. 页面太重。** 40 MB 的工厂参观视频自动播放、5 MB 未压缩的产品图、一个轮播插件加载六个 JavaScript 库。在大多数新兴出口市场占主导地位的中端安卓手机上，买家体验到的就是一块冻住的屏幕。修法并不光鲜：压缩并按尺寸裁切图片（提供 WebP 格式、按设备尺寸适配）、首屏以下的媒体延迟加载、非关键脚本延后执行、砍掉自动播放视频或改成带播放键的封面图。

**3. 晚加载元素造成的布局不稳。** Cookie 横幅、在线聊天插件、网络字体、没有标注尺寸的图片位，加载时会把内容往下推——这就是 CLS。在慢速连接下，这意味着「联系我们」按钮真的会躲开买家的手指。给每个动态元素预留空间（固定尺寸、font-display 设置、横幅占位）即可消除。

## 去哪里看你的真实数字

你不必相信办公室里的体验，也不必相信建站公司的演示：

- **Google Search Console → Core Web Vitals 报告**：你的真实实测数据，按页面组、移动端和桌面端分列——这就是 Google 使用的数字。它应该纳入 [Search Console 月度例行检查](/zh/news/google-search-console-exporters/)。
- **PageSpeed Insights**（pagespeed.web.dev）：输入任意 URL；上半部分是真实用户数据（「你的访客实际体验到的」），下半部分是实验室模拟，适合用来诊断原因。
- **诚实的人工测试**：清掉缓存，用一部中端手机走移动网络打开你的网站——最好通过目标市场的 VPN 出口。如果你自己都不愿意等，买家也不会等。

注意一个出口商常发现的规律：**英文首页达标（优化预算都花在了营销首页上），而各语言版本和深层产品页不达标**（它们继承了所有沉重的模板决策，却没人管）。Google 按页面类型评估；首页达标救不了产品页在[长尾关键词排名](/zh/news/industrial-long-tail-keywords/)上的惨淡表现。

## 回报最快的修复顺序

1. **CDN 挡在所有东西前面**——对远端市场收益最大的一项；通常只是配置调整，不是重做。
2. **图片纪律**——压缩、按尺寸适配、现代格式；在多数 B2B 网站上，图片占页面重量的 60%–80%。
3. **干掉或延后阻塞渲染的脚本**——聊天插件、统计代码、加载在页面头部的轮播库；大多数都可以在内容之后加载。
4. **预留布局空间**——每张图片和嵌入内容都标注尺寸；横幅和插件用占位块。
5. **一个月后复测**——实测数据是 28 天滚动窗口，改善会逐步显现；[GA4 的跳出与互动数据](/zh/news/ga4-export-website-metrics/)会比 Search Console 更早确认商业效果。

Core Web Vitals 不是 IT 部门的虚荣指标，它是「你的网站是否尊重忙碌买家的时间」的技术化表达——在买家真正所在的地方测量。我们的[网站建设团队](/zh/services/website-building/)为出口商建站时，默认就按目标市场通过全部三项指标来交付：边缘分发、克制的媒体处理、稳定的布局。[把你的网址发给我们](/zh/contact/)，我们会告诉你前三大市场的买家今天实际体验到什么。
