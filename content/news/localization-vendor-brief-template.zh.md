两家公司把同一份手册交给同一家本地化供应商。一家当天拿到准确报价，项目顺利推进；另一家拿到的是含糊的估价、三轮追问、中途调价，最终交付还错过了上线日期。差别几乎从不在供应商身上，而在需求简报。

本地化供应商是基于"不确定性"来报价和排期的。简报含糊，供应商要么在报价里加风险余量，要么碰运气——而一旦赌输，成本会以延期和返工的形式回到你头上。好的简报消除不确定性，省下的钱归你。

## 一份本地化简报必须包含什么

一份完整的简报一两页即可，回答八个问题：

1. **内容是什么？** 文档类型（手册、宣传册、网站、视频、课程）、主题领域，以及大致体量——文本按字数、视频按时长、排版按页数。
2. **你手里有什么文件？** 这是供应商最先问、客户答得最差的问题。"我们有个 PDF"不算答案——是可编辑的 PDF 还是扫描件？有没有源文件（InDesign、Word、FrameMaker、PPT）？有源文件通常能让 DTP 排版成本降低三分之一。
3. **哪些语言？** 语种变体要说清楚：巴西葡萄牙语还是欧洲葡语？拉美西语还是卡斯蒂利亚西语？简体中文还是繁体中文？
4. **用途是什么？** 法规申报、销售宣传册、内部培训，三者的质量标准和流程完全不同。用途决定流程。
5. **读者是谁？** 工程师、采购经理、终端消费者、监管人员——语气和术语选择跟着读者走。
6. **有哪些参考资料？** 以往译文、术语表、风格指南、品牌术语、你欣赏的竞品材料。每一份参考资产都在降低成本和风险。
7. **真实死线是什么？** 不是期望中的那个。如果展会日期定死，但宣传册可以提前一周先出电子版，就说出来——这样才有排期的腾挪空间。
8. **谁负责审批？** 指定回答术语问题、签收最终文件的人，以及他的响应时间。项目卡在"沉默的审批人"身上，比卡在翻译本身更多。

## 简报模板

下次询价时直接套用以下结构：

| 项目 | 示例内容 |
|---|---|
| 内容类型 | 产品安装手册，技术类 |
| 体量 | 约 12,000 字，45 页，30 张图 |
| 源文件 | InDesign 2024 打包文件 + 链接图片 + 参考用 PDF |
| 目标语言 | 德语、西班牙语（拉美）、阿拉伯语 |
| 用途 | 随产品交付；须与法规申报文件一致 |
| 读者 | 持证安装人员、技术分销商 |
| 参考资产 | 英文术语表（200 条）、上一版德语译文、品牌风格指南 |
| 死线 | 3 月 15 日交终稿；2 月 20 日前出报价 |
| 审批联系人 | Jane Wu，产品文档负责人，24 小时内回复 |
| 交付物 | 每种语言的印刷级 PDF + 打包源文件 |

## 让你多花钱的简报错误

- **只拿 PDF 去询价。** 如果一份要进入排版流程的文档，你只发去一份压平的 PDF，供应商只能按"提取+重建"报价。即使暂时不能提供源文件，也要说明它们存在——价差是实打实的。
- **隐瞒死线。** 有些采购怕"加急费"而隐瞒真实交期，结果更糟：供应商盲排产能，你的"突然加急"变成所有人的救火。有计划地赶工，报价远低于没计划的救火。
- **没有术语表，却有强烈意见。** 如果你会因术语问题打回译文，就请提前提供术语。"我们看到就知道对不对"是本地化行业最贵的一句话。
- **给五家供应商发同样的简报，却只比价格。** 简报的意义在于可比——但要比的是范围：报价是否包含 DTP、语言 QA、一轮修订、术语管理？最便宜的那一行，往往恰好剔除了决定译文能不能用的环节。
