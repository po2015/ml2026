每个出口商都有这么一条：那条能拿下订单的产品演示视频。销售团队每通电话前都发它，经销商每个月都来要它，它确实能转化——用英文。然后圣保罗或吉达的一位买家点开链接，看着一台他看不懂的机器，听着一门他只能半懂的语言在解说。对大多数 B2B 产品来说，每个市场重拍在经济上是荒谬的。好消息是：规划得当的演示视频可以分层本地化，而大多数层的成本远低于一天的拍摄。下面逐层讲。

## 第 0 层：先弄清你的视频里到底有什么

在讨论任何预算之前，先盘点视频的组成部分，因为每一部分的本地化方式都不同：

| 组成部分 | 例子 | 本地化选项 |
|---|---|---|
| 口述旁白 | 画外音、出镜主持人 | 配音 / voice-over / 字幕 |
| 屏幕文字 | 标题、标注、规格角标 | 编辑文字图层 / 覆盖补丁 |
| 屏幕或 UI 录屏 | 软件演示、HMI 面板 | 用目标语言重录 / 加标注 |
| 实拍画面 | 机器运转、手部操作 | 通常不动——这是通用层 |
| 音乐与音效 | 垫乐、转场音、点击声 | 不动（保留 M&E 声轨） |
| 片尾卡与 CTA | 联系信息、URL | 按市场重做 |

两项资产决定这件事是便宜还是痛苦：**工程文件**（Premiere/After Effects/DaVinci——文字在独立图层上）和 **M&E 声轨**（不含人声的音乐音效轨）。两样都有，第 1–3 层就是几天的工作量。如果你手上只有一个压平的 MP4，每一处文字修改都变成了像素级手术。*今天*就去找你的视频制作方要这两样东西，哪怕本地化是一年以后的事。

## 第 1 层：旁白——配音还是字幕？

市场说了算，不是你说了算。我们的[字幕与配音对照图](/zh/news/subtitles-vs-dubbing-by-market/)按地区拆分了偏好；简版结论：拉丁美洲、法国、德国和阿拉伯世界倾向配音；北欧、荷兰和亚太的大部分地区，即使是营销内容也乐意接受字幕。

具体到 B2B 演示视频，**解说式配音**（替换旁白、无需口型同步——因为大多数演示是画面加旁白，而不是人物对镜讲话）正中甜点区：AI 语音加母语质检的组合负担得起、速度快，质量由台本改编把控——我们[台本改编指南](/zh/news/dubbing-script-adaptation-timing/)中的纪律逐行适用。预算大致参照[成本框架](/zh/news/ai-dubbing-corporate-training-cost-quality/):AI 旁白加人工审校的费用是棚录演员的零头，而对于一条 4 分钟的演示，绝对金额无论哪种方案都不大。

## 第 2 层：屏幕文字

规格标注（「IP67」「45 Nm」「CE」）往往是通用的——数字和标准号不用翻译。需要翻译的是：描述性标签、卖点标题和章节标题。有工程文件，换文字图层是机械操作——但要小心两个经典陷阱：

- **文字膨胀**：德语和俄语会长出 20–30%；原本优雅地装下「Fast setup」的动画标注，现在得装下「Schnelle Einrichtung」。谨慎地缩小字号、缩写，或者重排动画时间——与文档相同的[膨胀纪律](/zh/news/text-expansion-translation-layout/)。
- **动画时序**：逐字擦入或与旁白同步的文字，必须按新音频重新对时，因为每种语言的句子结构不同。

没有工程文件？覆盖式「补丁」图形（一块与背景吻合的干净底板，上面放新文字）能覆盖大多数情况；动画很重的段落，可能值得只重做那一段。

## 第 3 层：UI 与屏幕录屏

如果演示里出现了产品的软件界面或 HMI 面板，决策树很短：

- **产品出厂带本地化 UI** → 用目标语言的 UI 重新录屏。其他一切做法都显得不可信。
- **产品 UI 只有英文** → 保留英文录屏，围绕它做本地化：翻译后的旁白解释画面内容，关键 UI 元素可以贴一个简短的翻译标注。永远不要伪造一个不存在的本地化 UI——买了产品的买家会发现真相。

## 第 4 层：外包装——缩略图、片尾卡、元数据

片尾卡承载着你的 CTA：按市场重做，放上本地联系路径（经销商名称、本地号码、本地化的落地页 URL）。如果演示视频放在 YouTube 上，元数据是半壁江山——本地化的标题、简介和多语言音轨，参见我们的 [YouTube 本地化指南](/zh/news/youtube-multi-language-audio/)。一条本地化得很漂亮、元数据却全英文的视频，只有不需要它本地化的人才搜得到。

## 务实的推进顺序

不要为所有市场本地化所有内容。排个序：

1. **王牌演示 × 头 2–3 个市场**先做（完整待遇：配音旁白、本地化文字、市场专属片尾卡）。
2. 长尾的视频和市场**只做字幕**——便宜、快，而且诚实。
3. **看数据**：分市场的观看时长和询盘归因，决定下一条完整本地化给谁——与培训内容通用的同一套[企业视频打法](/zh/news/video-localization-corporate-training-guide/)。

再说一个上游的建议：下次*制作*演示视频时，就为本地化而拍——文字放图层、交付分轨、尽量减少出镜讲话、画面通用。给摄像师的这一句要求，能把未来的本地化成本砍掉一半甚至更多。
