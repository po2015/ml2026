这个卖点无法抗拒：装一个挂件，网站角落就出现一个语言选择器——即时德语、西班牙语、日语，100 多种语言，零译者，零成本。一家制造商周一装上它，周二就骄傲地演示「我们的多语言网站」。到周五，三件事已经发生，而他们一件都看不见：德国经销商发来邮件，问为什么网站现在用一个机器生造的荒谬复合词称呼双方共有的产品；一位日本潜在客户在第一句话就关掉了页面（语域错得明明白白地喊着「机器人」）；而 Google 精确地没有收录其中任何一个字——因为 JavaScript 注入式翻译不产生任何可索引的页面。挂件分毫不差地完成了它的设计目标——演示效果好。问题在于，「演示效果好」和「能正常工作」是两种不同的产品。

## 这些挂件实际在做什么

几乎所有免费的「即时翻译」插件工作原理相同：JavaScript 把你的页面文本发送给一个机器翻译 API，然后**在访问者的浏览器里**即时替换文本。关键短语是*在浏览器里*：翻译内容从不存在于你的服务器上、你的 HTML 里，或任何 Google 能抓取的 URL 上。一些付费档位会生成服务端翻译的 URL——那是另一种产品，带着另一套问题（未经审校的 MT 大规模发布，见下）。搞清楚你装的是哪种机制，随后的一切失败就都有了答案。

## 五项隐性成本

**1. SEO 价值为零——往往为负。** 浏览器注入的翻译不产生可抓取页面，所以你的「多语言网站」恰好只用一种语言排名：原文。整套[国际 SEO 机制](/zh/news/international-seo-guide-chinese-manufacturers/)——hreflang、本地化 URL、逐语言元数据——都无处附着。而如果插件*确实*生成了未经审校的服务端 MT 页面，你可能发布数千个低质量页面，拖累整个域名的感知质量。流量和清白，你一样都得不到：真正能排名的[多语言站点结构](/zh/news/how-many-languages-export-website/)需要的是真实 URL 上的真实页面。

**2. 以机器速度损害品牌。** 未经审校的 MT 会犯标志性错误：翻译你的品牌名和产品名（一家叫「Apex」的公司变成了德语里的「山顶」；型号名变成一锅粥）、糟蹋技术术语（[术语库存在的意义正是防止这个](/zh/news/terminology-management-termbase/)）、选错语域和正式度（在[日语](/zh/news/japanese-b2b-website-trust/)、[韩语](/zh/news/korean-market-digital-expectations/)和德语商务语境里是致命的）。你的英文网站写着「精密工程」；挂件写出来的东西被你的买家截图转发当笑话。

**3. 版式与排版崩坏。** 注入的文本无视你的设计：德语长 30% 的字符串溢出按钮和菜单；阿拉伯语不切换 RTL（半数挂件实现把它渲染成左对齐且支离破碎）；CJK 文本回退到系统字体。真正的本地化为之编制预算的[文本膨胀](/zh/news/text-expansion-translation-layout/)和排版工作在这里完全缺席——而每一位访客都看得见。

**4. 隐私与合规暴露。** 页面内容——包括访客在你表单里输入的任何内容——都要经过一个第三方翻译 API 中转。对 GDPR 管辖下的欧盟访客，这条数据流需要披露和大多数挂件安装者从未配置过的法律依据；某些司法辖区的数据跨境规则让情况更糟。没人把自己的翻译挂件当成数据处理者；监管机构会。

**5. 机会成本——真正的账单。** 挂件最深的代价是覆盖面的幻觉：「我们已经搞定语言了」成了公司*不去*建设那三个真正能排名、能转化、经得起经销商审视的语言版本的理由。市场默默地得出结论：这家供应商不认真（正是那个[韩国经销商的故事](/zh/news/korean-market-digital-expectations/)）——这笔成本从不出现在任何发票上。

## 同样的投入，正经花能买到什么

诚实的对比不是「免费挂件 vs. 5 万美元的本地化项目」，而是：

| | 免费挂件 | 正经的最小本地化 |
|---|---|---|
| 可索引、可排名的页面 | ✗ 没有 | ✓ 逐语言 URL + hreflang |
| 母语买家信赖的质量 | ✗ 生 MT，语域错误 | ✓ 专业翻译 + [审校](/zh/news/in-context-translation-review/) |
| 品牌／术语控制 | ✗ 名称被翻译 | ✓ [术语库](/zh/news/terminology-management-termbase/)强制约束 |
| 版式／RTL／排版 | ✗ 边缘处崩坏 | ✓ 按文字体系设计 |
| 成本 | $0 + 隐性成本 | [10–15 页的分阶段档位](/zh/news/emerging-market-language-roi/)，每语言几千美元 |

分阶段入场——你的核心页面、专业翻译、1–2 个价值最高的语言——成本低于一单流失的经销商生意，也低于许多公司年度展会咖啡预算。如果预算真的为零，正确的做法是**更少语言，之后正经做**——一个只有英文但有可信路线图的网站，胜过 100 种语言的噪音。机器翻译本身不是反派：它有正当角色（内部理解、询盘速读、在受管[翻译流水线](/zh/news/human-vs-machine-translation-technical-content/)内做 MT＋人工后编辑）。反派是*未经审校*的 MT 穿着你的品牌招摇过市。
