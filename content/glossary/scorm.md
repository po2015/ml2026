SCORM (Sharable Content Object Reference Model) is the technical standard that lets an e-learning course and a learning management system talk to each other. A SCORM package is a zip file containing the course plus a manifest that tells the LMS how to launch it, bookmark progress, record completion, and report quiz scores.

Two versions dominate: SCORM 1.2 (2001) and SCORM 2004. Both are ancient by software standards, but they remain the lingua franca of corporate training — virtually every LMS in the world accepts them, from Moodle to SAP SuccessFactors.

SCORM matters for localization because a translated course must be repackaged, not just reworded. Text lives inside the authoring tool's project; completion logic, navigation, and scoring live in the package structure. A proper localization rebuilds the course in the authoring tool, then re-exports and re-validates the SCORM package so it still reports correctly.
